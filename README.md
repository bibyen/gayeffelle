# gayeffelle


richmond st leonards hackathon

## quick start

### frontend

Spin up the UI by running the following from `./frontend/src`:

```bash
npm run dev
```

### backend

prerequisites:

1. docker daemon up and running!
2. supabase installed:
   `brew install supabase/tap/supabase`

start up the server:

1. `cd backend`
2. `supabase start`
3. `./gradlew bootRun`
